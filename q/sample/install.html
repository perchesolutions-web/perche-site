All three can be used together. They show the same quote tool, and every request is emailed to you.

Full tool on a page

Button that opens a pop-up

A button wherever you paste the code. Visitors get the quote tool on top of your page and close it to keep browsing. Best on your home page and service pages.

Floating button on every page

A small "Instant quote" button stays in the bottom corner of every page. Paste the code once, in the place your builder keeps code for the whole site. Easiest way to reach every visitor.

<script src="https://perchesolutions.com/embed.js" data-client="sample" data-mode="floating" async></script>

With this code on your site, any button or link you point to #instant-quote opens the quote tool too, so your website's own buttons can open it.

2. Steps for your website builder

Not sure which you use? It's usually in your website's bill, or at the bottom of your site's pages.

Wix

Any Wix plan: a button

  1. In the Wix Editor, click Add Elements (+), then Button, and place it.
  2. Set its text to something like "Get an instant quote". Click the link icon, choose Web Address, paste your quote page link, and choose New window.
  3. Publish.

Premium plan: the full tool on a page

  1. Click Add Elements (+), then Embed Code, then Embed HTML.
  2. Choose Website address and paste the web address from "Builders that ask for a web address" above.
  3. Stretch it to full width and make it about 1000 px tall. In the mobile editor, make it about 1300 px tall.
  4. Publish, then check the page on your phone. Wix shows embeds at a fixed size, so the tool scrolls inside its box if a step is taller.

Premium plan with your own domain: floating button on every page

  1. In your site's dashboard, go to Settings, then Custom Code (under Development & integrations).
  2. Click Add Custom Code, paste the floating button code, choose All pages, and place it in Body - end. Click Apply.
Squarespace

Core, Plus or Advanced plan

  1. Edit the page, click an insert point (+), and add a Code block.
  2. Paste the "Full tool on a page" or "Button" code. Leave Display Source off, then save.
  3. Code blocks often don't run while you're logged in. Check the page in a private browser window.

Floating button on every page

  1. Search the Squarespace menu for Code Injection.
  2. Paste the floating button code in Footer and save.
  3. Any Squarespace button can then open the quote tool: set its link to #instant-quote.

Basic plan

  1. Basic doesn't run custom code. Add a Button block and link it to your quote page.
WordPress

On a page

  1. Edit the page and add a Custom HTML block where the tool should go. (Elementor: the HTML widget. Divi: the Code module.)
  2. Paste the "Full tool on a page" or "Button" code, then Update.

Floating button on every page

  1. Use your theme's footer code setting, or a header and footer code plugin such as WPCode.
  2. Paste the floating button code in the footer section and save.

WordPress.com

  1. Custom code needs a WordPress.com plan that allows plugins. On other plans, add a Buttons block linked to your quote page.
GoDaddy

Full tool on a page

  1. Edit your site, click Add Section, search for HTML, and add it where the tool should go.
  2. Paste the "Full tool on a page" code into Custom Code. Leave Forced Height empty.
  3. Publish, then check the page on your phone. If the tool is cut off, set Forced Height to 1100.

A button

  1. Most GoDaddy sections have a button. Set its link to your quote page.
  2. GoDaddy runs pasted code in a box of its own, so the "Button" code opens the quote page in a new tab there, and a floating button for every page isn't possible.
Webflow
  1. Drag a Code Embed element onto the page, paste the "Full tool on a page" or "Button" code, and save. Custom code needs an active site plan.
  2. Floating button on every page: Site settings, then Custom code, then Footer code. Paste it and save.
  3. Your own buttons can open the quote tool: set their link to #instant-quote.
  4. Publish.
Shopify
  1. Go to Online Store, then Themes, then Customize. Add a Custom Liquid section and paste the "Full tool on a page" or "Button" code. Save.
  2. Floating button on every page: add another Custom Liquid section in the footer with the floating button code.
Square Online
  1. On a Plus or Premium plan: edit your site, click Add, then Section, then Embed code, and paste the "Full tool on a page" code. Publish.
  2. On any plan: add a button linked to your quote page.
Google Sites
  1. Click Insert, then Embed, then By URL. Paste the web address from "Builders that ask for a web address" and insert it.
  2. Drag the box to make it tall, about 1000 px, then Publish.
  3. Or add a Button (Insert, then Button) linked to your quote page.
Another builder or a custom website
  1. Paste the "Full tool on a page" or "Button" code into the page's HTML where it should appear. Most builders (Duda, Weebly, Jimdo and others) have an "HTML" or "Embed code" element for this.
  2. For the floating button, paste its code just before </body> on every page, or in the site-wide footer code setting.
  3. If your site was built by a marketing company, send them this page.
  4. No way to add code? A button or menu link to your quote page always works.
